# Reposer〜ルポゼ〜 更新ガイド

## ファイルの役割

- `src/pages/index.astro`：1ページHPの構成・文章・写真の配置。
- `src/components/Hero.astro`：画像内の文字を生かすヒーロー、端末別の画像配信、予約パネル。
- `src/data/hero.ts`：PC・タブレット・スマートフォンそれぞれのヒーロー画像と配信サイズ。
- `src/styles/hero.css`：ヒーローの全画面表示と端末別レイアウト。
- `src/data/site.ts`：店名・電話・受付時間・予約先・コースとオプション料金。
- `src/styles/global.css`：黒・金・アイボリーの配色、文字、PC／スマートフォンのレイアウト。
- `src/scripts/main.ts`：モバイルメニュー、スクロール時のヘッダー、表示アニメーション。
- `src/components/Icon.astro`：操作用SVGアイコン。
- `src/components/Ornament.astro`：装飾用SVG。
- `public/reposer.svg`：Rの文字を用いたサイトアイコン。

## 店舗情報・メニューの変更

`src/data/site.ts` の `site`、`courses`、`options` を編集します。

- 電話番号は `phone` と `phoneHref` の両方を変更してください。
- 受付時間は `reception`、`receptionDisplay`、`receptionNote` を更新してください。`receptionDisplay` がファーストビューの「9:30 — 27:00」に使われます。
- `webUrl` と `lineUrl` がすべての外部予約ボタンで共通使用されます。
- 料金は数値で入力するとカンマ区切りで表示されます。
- 検索表示用の `title`・`description` も、店名や料金を変えた場合に更新してください。

### ヒーロー画像の端末別設定

ヒーロー画像だけは `src/data/hero.ts` で設定します。現時点では追加の専用画像がないため、PC・タブレット・スマートフォンのすべてに現在の `IMG_0071.png` を使用し、端末に合わせた解像度で配信します。画素を書き換える生成やトリミングは行っていません。

| 画面幅 | 画像設定 | 配信する幅の候補 |
| --- | --- | --- |
| 1101px以上 | `heroImages.desktop` | 1280 / 1600 / 1920 / 2424px |
| 761〜1100px | `heroImages.tablet` | 768 / 1024 / 1280 / 1600 / 2048px |
| 760px以下 | `heroImages.mobile` | 480 / 640 / 800 / 960 / 1280px |

画像はWebP・品質95の設定で書き出され、ブラウザーが画面幅と画素密度に応じて選択します。元画像より大きな候補は元画像の幅に制限しています。

画像内の「Reposer」「ルポゼ」「特別な癒しと安らぎを…」を生かすため、同じ場所へ重ねていたHTMLの店名・キャッチコピー・装飾と暗いフィルターは撤去しています。読み上げ用のh1と画像の代替テキストは残しています。

ヒーロー全体は画面の高さに合わせ、固定ヘッダーとスマートフォンの予約バーの領域を確保します。画像は `object-fit: contain` で全体を表示します。縦長画面では横長バナーの上下にシャンパン系の余白ができますが、店名やコピーが切れないことを優先しています。予約ボタンは画像下の独立したパネルへ移動しています。

専用画像を追加する場合は、`hero.ts` で画像をimportし、`heroImages.tablet` または `heroImages.mobile` の参照先を変更します。PC用バナーはそのまま維持できます。スマートフォン専用画像は、店名・コピーを収めた縦長構図が適しています。画面全体にはヘッダーと予約パネルも含まれるため、端末の画面比率と画像比率を完全に一致させる必要はありません。

## 今回の掲載判断

- 今回ご提示の情報を掲載の基準としています。
- メニューは90分17,000円・120分22,000円、オプションは極液3,000円・アロマオイル2,000円のみ掲載しています。
- 受付時間は9:30〜翌3:00（27:00）とし、営業終了時刻とは区別しています。
- クレジットカード手数料10%を料金欄と店舗情報に掲載しています。
- 税込／税別は未提示のため、どちらとも記載していません。
- 所在地は宮崎県都城市までです。未提示の番地、郵便番号、地図のピンは追加していません。
- ご利用の流れは計画に沿った一般的な予約案内です。店舗の実際の運用と異なる場合は文章を調整してください。
- 資格・施術効果・口コミ・スタッフ情報・追加コースは追加していません。
- 独自の予約フォーム・決済機能は設けず、ご指定の予約サービスにリンクしています。

## 検索表示・公開URL

日本語設定、title、description、OGPのタイトル・説明、サイトアイコンを実装しています。正式な公開URLが未指定のため、canonical、og:url、OGP画像の絶対URL、サイトマップは設定していません。公開先の確定後に追加できます。Google Fontsを読み込み、取得できない場合は端末のフォントで表示します。

## 動きと操作

内容は通常状態で表示し、JavaScriptが利用できる場合のみ画面外から入る要素へフェードを追加しています。最初から表示範囲にある要素はスクロール演出の対象にしません。動きを減らす端末設定ではアニメーションを無効にします。

モバイルメニューはdialog要素を使用し、閉じるボタン・Escキー・背景クリック・項目選択で閉じます。ページ下部に電話・WEB・LINEの固定予約バーがあります。

```powershell
npm exec astro dev logs
npm exec astro dev stop
```
