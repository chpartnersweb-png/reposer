# Reposer〜ルポゼ〜｜1ページHP制作プラン

作成日：2026年11月6日  
対象：宮崎県都城市のメンズエステ「Reposer〜ルポゼ〜」  
段階：構成・デザイン・予約導線の計画。サイト実装・公開は本計画に含まない。

## 1. 制作の目的

華やかな第一印象から、サロンの考え方、料金、店舗情報、予約へと自然につながる1ページを制作する。初めて訪れる方が「どのようなお店か」「料金はいくらか」「どう予約するか」を迷わず確認できる構成とする。

主な成果指標は、電話・エステ魂・LINEの各予約導線のクリック。実際の予約成立数とは区別する。計測は必要性と導入するサービスを決めた後に設定する。

## 2. デザインコンセプト

**華やかさの中に、本物の安らぎを。**

深いブラックとシャンパンゴールドを軸に、写真を大きく見せる。金色はロゴ、見出し、細い装飾線、主要ボタンに集約し、写真と余白を引き立てる。店舗の温かさも伝わる、ラグジュアリーなサロンサイトを目指す。

| 要素 | 方針 |
| --- | --- |
| 背景 | オブシディアンブラック `#101011`、補助にチャコール `#1D1B1A` |
| アクセント | シャンパンゴールド `#C6A66A`、淡い金色 `#E7D4AA` |
| 本文 | ウォームホワイト `#F3EEE6`。本文に濃淡の弱い金色を使わない |
| 書体 | 日本語見出しは明朝体、本文・料金・ボタンは可読性の高いゴシック体 |
| 写真 | 掲載許可と被写体を確認した支給写真を主役にする |
| 装飾 | 細い金の罫線、控えめな光のグラデーション、余白 |
| レイアウト | 全幅ヒーロー、大きな写真と短い文章、料金の横組み一覧で変化をつける |

`src/assets/IMG_0063.jpg` は黒・金・装飾的な書体を用いた料金表画像。色と世界観の参考にする。料金は更新しやすく、スマートフォンでも読めるHTMLテキストで掲載する。画像内の追加コース・オプションは今回の依頼に含まれないため、自動的にメニューへ追加しない。

`src/assets/IMG_0072.jpg` は室内の飾り棚等を写した写真。空間紹介の候補とする。残りの画像は制作時に内容と用途を確認する。生成・素材写真を使用する場合はイメージ表現に限定し、実際の店舗・スタッフと誤認させない。

## 3. ページ全体の構成

```text
ヘッダー
  ↓
ファーストビュー：世界観と予約入口
  ↓
コンセプト：お店の考え方と安心感
  ↓
コース・オプション：時間と料金を明確に
  ↓
空間紹介：写真でサロンの雰囲気を伝える
  ↓
ご利用の流れ：予約から来店まで
  ↓
店舗情報・アクセス：受付時間、支払い、駐車場
  ↓
ご予約・お問い合わせ：3つの予約方法
  ↓
フッター
```

### 3-1. ヘッダー

- 店名または正式ロゴを配置する。
- PCは「コンセプト／メニュー／空間／アクセス」と予約ボタンを配置する。
- スマートフォンは店名、予約入口、メニューボタンに整理する。
- ページ内リンク先の見出しが固定ヘッダーの下に隠れないようにする。

### 3-2. ファーストビュー

画面いっぱいに写真を敷いた構成。写真に暗いグラデーションを重ね、店名と短いコピーを中央付近に配置する。スマートフォンでは写真の焦点と文字位置を個別に調整する。

掲載コピー案：

> 華やかさの中に、本物の安らぎを。  
> Reposer〜ルポゼ〜  
> 宮崎県都城市のメンズエステ

補足は「完全予約制」「受付9:30〜翌3:00」「年中無休」に絞る。主要ボタンは「WEB予約へ」、補助ボタンは「LINEで予約」。電話はヘッダーとスマートフォン下部の固定導線から利用できるようにする。

ヒーローに使える横長の写真がない場合は、支給写真の切り出しを検討する。十分な品質が確保できない場合は、黒・金の抽象背景と店名で世界観をつくり、実写は空間紹介に配置する。

### 3-3. コンセプト

掲載文案：

> 確かな技術と心を込めたおもてなしで、  
> 安心して身を委ねられる、上質な癒しの時間を。

「完全予約制」「3ルーム」「完全安心健全店です。」を、短い説明とともに整理する。療法の効果、資格、スタッフの経歴、完全個室など、未提示の情報は記載しない。

### 3-4. コース・オプション

2コースを大きく見せ、所要時間と金額を一目で比較できる料金一覧にする。人気表記はご提示情報に基づく店内の案内として扱う。

| コース | 時間 | 料金 | 表記 |
| --- | --- | --- | --- |
| ゴージャスコース | 90分 | ¥17,000 | 人気No.1 |
| ゴージャスコース | 120分 | ¥22,000 | 人気No.2 |

| オプション | 料金 | 表記 |
| --- | --- | --- |
| 極液 | ¥3,000 | 人気No.1 |
| アロマオイル | ¥2,000 | 人気No.2 |

オプションの施術内容や効能は推測して書かない。税込・税別の表記は確認後に統一する。お支払い方法「現金／クレジットカード」と「クレジットカード決済は手数料10%」を料金の近くにも表示する。手数料の計算対象や追加料金の有無は公開前に確認し、総額を誤認させない案内にする。

料金一覧の後に予約入口を配置し、ページ末尾まで移動せず予約へ進めるようにする。

### 3-5. 空間紹介

支給写真から、室内全体と細部を組み合わせた大小の写真構成をつくる。PCは写真のサイズに変化をつけ、スマートフォンは縦に並べて自然に閲覧できるようにする。写真の内容が確認できるまでは部屋名、設備、用途を断定しない。

### 3-6. ご利用の流れ

以下は確認用の掲載案とし、実際の運用に合わせて確定する。

1. 電話・エステ魂・LINEから希望日時とコースを連絡する。
2. 店舗からの案内に従って、予約内容と来店方法を確認する。
3. 予約日時に来店する。

自動的な予約確定、即時返信、当日予約対応などは約束しない。予約画面の操作や確定条件は外部サービスの実際の仕様に従う。

### 3-8. ご予約・お問い合わせ

| 導線 | 表示案 | 遷移先 |
| --- | --- | --- |
| エステ魂 | エステ魂でWEB予約 | https://estama.jp/shop/49703/ |
| LINE | LINEで予約・問い合わせ | https://line.me/ti/p/k56BRLhubq |
| 電話 | 電話で予約 070-6605-0201 | tel:07066050201 |

エステ魂は指定された店舗ページへのリンクとして設置する。直接予約画面へのリンクを採用する場合は、URLと動作を確認してから変更する。LINEはご提示のURLをそのまま使用し、別形式のURLへ推測で変換しない。アカウントが対象店舗に接続するかは制作時の実機確認項目とする。

スマートフォン下部には「電話／WEB予約／LINE」の固定バーを配置する。主導線はWEB予約とし、電話とLINEも常時アクセスできるようにする。本文やフッターに重ならない余白と端末下端の安全領域を確保する。

### 3-9. フッター

店名、電話、受付時間、ページ内リンク、コピーライトを掲載する。プライバシーポリシーが必要となる問い合わせフォームや計測サービスを追加する場合は、実際の取り扱いに沿った案内を用意する。

## 4. UI・UXと動き

- スマートフォンの文字サイズを本文16px程度から調整し、価格と予約ボタンの読みやすさを優先する。
- ボタンのタップ領域は44px以上を目安に確保する。
- 色だけで人気コースや操作状態を区別せず、文字も併記する。
- 写真と文章は短いフェードイン、細い装飾線は控えめに表示する。
- 画面上で常に動く粒子、強い点滅、長いローディング演出は採用しない。
- 動きを減らす端末設定に対応し、演出が無効でも内容を読めるようにする。
- メニュー、ページ内リンク、予約ボタンをキーボードでも操作できるようにする。

## 5. 実装・検索表示の計画

既存のAstroプロジェクトを利用し、1ページの静的サイトとして制作する。料金・店舗情報・予約URLをデータとして分離し、更新しやすくする。写真は用途に合った大きさへ最適化し、最初に表示する写真を優先読み込みする。予約導線は外部サービスへのリンクとし、独自の予約システムや決済機能は今回の範囲に含めない。

検索結果のタイトル案：

> 都城市のメンズエステ Reposer〜ルポゼ〜｜完全予約制

説明文案：

> 宮崎県都城市のメンズエステ「Reposer〜ルポゼ〜」。華やかさの中に、本物の安らぎを。ゴージャスコース90分17,000円・120分22,000円。完全予約制、駐車場あり。電話・エステ魂・LINEからご予約いただけます。

ページは日本語設定とし、見出し、画像の代替テキスト、OGPを整える。公開URL確定後にcanonical、サイトマップ等を設定する。構造化データは実装時に適切な種別を確認し、確認済みの事業情報のみを用いる。未確認の詳細住所、口コミ評価、座標、営業終了時刻は追加しない。検索順位やインデックス登録時期は制作成果として保証しない。

## 6. 公開前に確認する情報

| 確認事項 | 理由と現時点の扱い |
| --- | --- |
| 受付時間・営業時間の整合 | ご提示は9:30〜27:00受付、エステ魂は9:00〜翌4:00。計画はご提示内容を優先し、営業終了時刻は未確定とする |
| 税込・税別 | 料金に未指定のため、推測して表記しない |
| クレジットカード決済手数料 | 10%の計算対象、表示内容、対応ブランドを確認する |
| その他の費用 | 指名料・延長料等の有無と、提示料金に含まれる内容を確認する |
| 住所の公開範囲 | 市までの表記を維持するか、詳細住所・郵便番号・地図を公開するかを決める |
| 来店・予約確定の流れ | 店舗からの連絡方法、場所の案内方法、変更・キャンセルの案内を確認する |
| 写真・ロゴ | 使用許可、実際の店舗写真であること、掲載用途、正式ロゴの有無を確認する |
| 外部予約リンク | エステ魂の予約入口とLINEの遷移先を確認する |

追加のセラピスト紹介、出勤表、口コミ、クーポンなどは今回のご提示情報に含まれないため、初期構成には設けない。

## 7. 制作の進め方と成果物

1. 掲載内容と写真、公開前の確認事項を整理する。
2. スマートフォンを基準にワイヤーフレームを作成する。
3. ヒーロー・料金部分を中心にデザインを具体化する。
4. Astroで各セクション、ページ内移動、予約導線を実装する。
5. 表示幅、文字、リンク、画像の読み込み、キーボード操作、動きを確認する。
6. 公開URLと掲載内容を確定し、公開後に実ページを確認する。

実装時は作業対象に対応するAstro公式ガイドを参照する。開発サーバーが必要な場合は、プロジェクトのAGENTS.mdに従い `astro dev --background` で起動し、`astro dev status`・`astro dev logs`・`astro dev stop` で管理する。

予定する成果物は、レスポンシブ対応の1ページHP、最適化した画像、更新しやすい店舗・メニューデータ、基本的な検索表示設定、更新方法の説明資料。
